## 🏛️ Engineering Philosophy & Architectural Standard

I build backend systems designed for long-term maintainability and business rule integrity by enforcing a strict **4-Layer Clean Architecture**:

| Layer | Core Responsibility | Key Implementation Patterns |
| :--- | :--- | :--- |
| **1. Domain** *(Core)* | Pure business logic & invariants with **zero external dependencies**. | Rich Domain Entities, State Machines, Value Objects, Domain Exceptions. |
| **2. Application** *(Use Cases)* | Orchestrates domain workflows and defines system boundaries. | Application Services, DTOs, Request/Response Contracts, Repository Interfaces, Validation Pipelines. |
| **3. Infrastructure** *(Adapters)* | Implements persistence, external APIs, and cloud services. | **EF Core** (Code-First & Migrations), **PostgreSQL / SQL Server**, **Microsoft Azure** (Blob Storage, Key Vault), **QuestPDF**, **EPPlus**. |
| **4. Presentation** *(API / Web)* | Entry point, HTTP pipeline, security, and API documentation. | **ASP.NET Core Web API (.NET 8/9/10)**, **Identity & JWT** (RBAC/Claims), Global Exception Handling, **Scalar / Swagger (OpenAPI)**. |

## 💼 Featured Engineering Case Studies

### 📚 1. SkillHub — Enterprise Workshop & Enrollment Management Platform
> **Backend & Clean Architecture (.NET 10)** · [🔗 **Explore Repository**](https://github.com/juanjo2409/SkillHub)

Enterprise training center platform engineered to enforce complex academic scheduling and enrollment invariants.

* **Architecture & Design:** Built from the ground up with **Clean Architecture**, **Domain-Driven Design (DDD)**, and **SOLID** principles.
* **Core Business Rules:** Automated capacity control, duplicate enrollment prevention, real-time schedule conflict detection, and audit-logged cancellation/re-enrollment workflows.
* **Enterprise Integrations:**
  * High-speed bulk data ingestion from Excel spreadsheets via **EPPlus**.
  * Automated generation of verifiable academic PDF certificates using **QuestPDF**.
  * Modern, interactive OpenAPI documentation powered by **Scalar**.
* **Stack:** `.NET 10` · `ASP.NET Core Web API & MVC` · `EF Core 10` · `PostgreSQL` · `QuestPDF` · `EPPlus` · `Tailwind CSS`

### 🏆 2. FrameRent — Audiovisual Equipment Rental & Lifecycle System
> **Backend & Clean Architecture (.NET)** · [🔗 **Explore Repository**](https://github.com/juanjo2409/FrameRent)

Full-stack rental management platform engineered under strict enterprise architecture standards to handle inventory availability and contract lifecycles.

* **Architecture & Design:** Structured using **Clean Architecture**, **SOLID** principles, **Value Objects**, and rich domain entities governed by state machines.
* **Core Business Rules:**
  * Real-time stock availability verification through optimized **LINQ date-overlap queries**.
  * End-to-end rental state machine (`Pending` ➔ `Approved` ➔ `Delivered` ➔ `Returned`) with automated **late-fee calculation (`LateFee`)**.
  * Strict policy enforcement (maximum 15-day rental duration and up to 3 concurrent active rentals per customer).
* **Technical Highlights:** Fully containerized with **Docker Compose**, secured via **ASP.NET Core Identity & JWT**, and paired with an MVC client consuming the API via strongly-typed `HttpClient` services.
* **Stack:** `.NET` · `ASP.NET Core Web API / MVC` · `EF Core` · `PostgreSQL` · `Docker Compose` · `JWT & Identity`
